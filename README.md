# qc-skill

> Coding Agent 标注质检助手 —— 判断每一轮 AI 编码产物是否达标，并生成下一轮提示词。

## 简介

`qc-skill` 是一个面向 **AI 编码标注场景**的质检 Skill，用于评估 Coding Agent（如 Trae、Cursor、Antigravity）每一轮输出是否满足提示词要求。

它会：

- 自动解析当前轮次的提示词（从消息中读取或从历史中向前恢复）
- 读取工作区代码、diff、日志等证据
- 按固定格式输出质检结论（任务类型 / 业务领域 / 是否满意 / 下一轮 Prompt）
- 在质检前自动做 git 快照
- 把每条质检记录追加写入项目根目录上一级的 `qc.md`

## 安装

确保本地已安装 [Node.js](https://nodejs.org/)，然后在项目目录下运行：

```bash
npx skills add skyyewen/qc-skill
```

安装后，Skill 会自动部署到当前项目对应的 Agent 配置目录（`.gemini/skills/`、`.cursor/skills/` 等），无需手动配置。

## 使用方法

在支持 Skill 的 AI 编码助手中，通过以下方式调用质检：

```
@qc
```

```
@qc 上一轮的提示词：'''实现一个登录页面，支持表单验证'''
```

```
@qc 上一轮的提示词：'''...''' Trae的代码理解：'''...'''
```

| 调用方式               | 说明                           |
| ---------------------- | ------------------------------ |
| `@qc`                  | 自动向前恢复最近一条可用提示词 |
| `@qc <提示词>`         | 使用当前消息中明确给出的提示词 |
| `$qc` / `$qc <提示词>` | 同上，`$` 前缀等价             |

> **注意**：调用 `@qc` 后将进入只读质检模式，不会修改任何业务代码。

## 输出格式

质检结论始终包含以下两个固定部分：

```
【表格填报信息】
- 任务类型：...
- 业务领域：...
- 修改范围：...
- 任务是否完成：...
- 产物及过程是否满意：...
- 对产物不满意原因：...
- 对过程不满意原因：...

【下一轮发给模型的 Prompt】
- ...
```
